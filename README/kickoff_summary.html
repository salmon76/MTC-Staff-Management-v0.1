📱 Tier 1 User Channels

1. ช่องทางการใช้งานฝั่งผู้ใช้งาน (Tier 1: User Presentation & Client Channels)

สรุป 3 ช่องทางหลักในการเข้าถึงระบบ MTC Staff Management สำหรับผู้รับใช้ ศิษยาภิบาล และผู้ดูแลระบบ

💡 คำอธิบายรายละเอียด 3 ช่องทางผู้ใช้งาน (Client Channels Breakdown)

💬 LINE App (LIFF Gateway)

เข้าผ่าน LINE Official Account ไม่ต้องโหลดแอป รองรับ SSO & Quick Rich Menu สะดวกต่อผู้รับใช้ในการเช็กตารางและรับแจ้งเตือน

💻 Web Browser (Mobile & Desktop)

หน้าเว็บ PWA/Responsive UI สำหรับบุคลากร และศิษยาภิบาลเข้าดูข้อมูล จัดการตาราง และยื่นคำขออนุมัติต่างๆ ได้ทุกอุปกรณ์

🖥️ Backoffice CRM Admin Portal

แผงควบคุมระบบหลังบ้านสำหรับเจ้าหน้าที่คริสตจักร บริหารทะเบียนบุคลากร คลังอุปกรณ์ ใบแจ้งซ่อม และกำหนดสิทธิ์ใช้งาน (RBAC)

⚡ Solution Overview Architecture

2. ภาพรวมสถาปัตยกรรมและการทำงานของระบบ (System Overview 3 Zones)

โครงสร้างการเชื่อมโยงไร้รอยต่อแบ่งตาม 3 Zones การทำงานหลัก

💡 คำอธิบายภาพรวมการทำงานของระบบ 3 Zones (Detailed Breakdown)

Zone 1: User Gateway

Front-end: เข้าถึงง่ายผ่าน Line Official Account โดยใช้ Rich Menu เป็นทางเข้าหลัก ผู้รับใช้และบุคลากรเข้าใช้งานผ่านมือถือได้ทันทีโดยไม่ต้องติดตั้งแอปพลิเคชันเพิ่มเติม

Zone 2: Processing Engine

System Engine: Web App MTC Staff ทำหน้าที่เป็น Interface สำหรับกรอกข้อมูล, แสดงผลรายงาน และเชื่อมต่อ Line Messaging API เพื่อส่งการแจ้งเตือนอัตโนมัติ

Zone 3: Database

Data Storage: บันทึกข้อมูลลง Supabase / PostgreSQL ปลอดภัยบน Cloud พร้อมรองรับการ Sync ข้อมูลสู่ Central Server ในอนาคต

📊 Business Impact & UX

3. ประสบการณ์ผู้ใช้งาน และคุณค่าทางธุรกิจ (User Experience & Business Value)

เปรียบเทียบรูปแบบการแจ้งเตือนทาง LINE และผลลัพธ์เชิงบริหารของคริสตจักร

📱 คำอธิบายประสบการณ์ผู้ใช้ (User Experience Breakdown)

  • LINE Push Alert Notification: ระบบส่งข้อความแจ้งเตือนเตือนตารางเวรรับใช้ล่วงหน้าอัตโนมัติเข้าสู่ LINE ของผู้รับใช้แต่ละท่าน เช่น "แจ้งเตือน: ท่านมีเวรรับใช้ในวันพรุ่งนี้ (09:00 - 12:00) กรุณาเตรียมตัว"
  • User Action: ผู้รับใช้รับ Notification และกดสลับดูตารางงานส่วนตัวและตารางเพื่อนร่วมรับใช้ได้ทันที ลดขั้นตอนการสอบถามในกลุ่ม LINE

🏆 คำอธิบายคุณค่าทางธุรกิจ (Business Value Breakdown)

  • Core Function: จัดทำตารางเวรรับใช้รายสัปดาห์แบบอัตโนมัติ ช่วยลดเวลาและภาระงานของผู้จัดตารางลงอย่างมีนัยสำคัญ
  • Usage Pattern: สมาชิกและผู้รับใช้สามารถตรวจสอบตารางเวรย้อนหลังและล่วงหน้าได้ด้วยตนเองตลอด 24 ชั่วโมง
  • Business Benefit: ลดความสับสน (Confusion) ในการจัดตาราง และป้องกันการลืมหน้าที่ของมัคนายกและทีมรับใช้ได้อย่างยั่งยืน
📍 1. จุดเริ่มต้นและ 4 ปัญหาหลักที่เราต้องการเปลี่ยนแปลง (Pain Points)
🔴 Pain Point 1
📝

เอกสารกระดาษ & LINE Group กระจัดกระจาย

  • คำขออนุมัติ การแจ้งลา หรือการมอบหมายงาน ตกหล่นในกลุ่ม LINE
  • ค้นหาประวัติย้อนหลังยาก และไม่มีระบบแจ้งเตือนที่เป็นทางการ
  • เป้าหมายการเปลี่ยน: ย้ายสู่ศูนย์กลางข้อมูลหนึ่งเดียว (Single Source of Truth) บนเว็บและ LINE
🔴 Pain Point 2
📦

อุปกรณ์ยืม-คืนไม่มีหลักฐาน & ช่างซ่อมช้า

  • ไมโครโฟน โปรเจกเตอร์ ยืมไปใช้แล้วไม่รู้ว่าอยู่ที่ใคร ไม่มีคนรับผิดชอบ
  • เมื่ออุปกรณ์ชำรุด ไม่มีใครแจ้งซ่อม ช่างซ่อมช้าเพราะไม่มีตัวนับเวลา (SLA)
  • เป้าหมายการเปลี่ยน: สแกน QR Code + เซ็นชื่อดิจิทัลรับยืมคืน + แจ้งซ่อมตามเวลา SLA
🔴 Pain Point 3
📅

ตารางปรนนิบัติ (Serving Roster) ชนกัน

  • ผู้จัดตารางไม่รู้ว่าผู้รับใช้ติดภารกิจอื่นหรือแจ้งลาล่วงหน้าหรือไม่
  • เกิดปัญหาขาดคนรับใช้หน้างานในวันอาทิตย์อย่างกะทันหัน
  • เป้าหมายการเปลี่ยน: ระบบเช็กตารางชนอัตโนมัติ และเตือนผู้รับใช้ล่วงหน้า
🔴 Pain Point 4
🔒

ฐานข้อมูลทะเบียนคริสตจักรเสี่ยงไม่ปลอดภัย

  • ข้อมูลสมาชิกและบุคลากรเก็บกระจายใน Excel ไม่มีการจำกัดสิทธิ์ (RBAC)
  • เสี่ยงต่อข้อมูลรั่วไหล และไม่สอดคล้องกับมาตรฐานคุ้มครองข้อมูลส่วนบุคคล (PDPA)
  • เป้าหมายการเปลี่ยน: จัดเก็บในตู้เซฟดิจิทัล ล็อกสิทธิ์ดูข้อมูลเฉพาะผู้มีหน้าที่
📊 2. ตารางรับใช้แบบเดิม (As-Is Process vs To-Be Platform)
📑

ภาพตารางรับใช้เดิมแบบกรอก Excel (As-Is Roster Sheet)

รูปแบบไฟล์ Excel spreadsheet ดั้งเดิมที่ใช้จัดผู้รับใช้ในปัจจุบัน

🔴 ข้อจำกัดของรูปแบบเดิม (As-Is Excel):
  • จัดตารางใน Excel ไม่เชื่อมต่อกับสถานะการลาหรือภารกิจอื่นของผู้รับใช้
  • เมื่อมีคนแจ้งเปลี่ยน/ติดงาน ต้องพิมพ์แก้ไขไฟล์ใหม่และส่งไฟล์เข้ากลุ่ม LINE ซ้ำๆ
  • เกิดปัญหาตารางชนกัน และผู้รับใช้ขาดหน้างานในวันอาทิตย์โดยไม่ทราบล่วงหน้า
🟢 การยกระดับสู่อนาคต (To-Be Platform):
  • จัดตารางผ่านระบบดิจิทัล ดึงรายชื่อบุคลากรและศิษยาภิบาลจาก Database
  • ระบบตรวจสอบสถานะการลาและตารางชนให้อัตโนมัติล่วงหน้า 100%
  • แจ้งเตือนเตือนตารางรับใช้ตรงไปยัง LINE ของผู้รับใช้แต่ละท่านทันที
📱 3. ตัวอย่างหน้าตาแอปพลิเคชันฝั่งผู้ใช้งาน (7 Mobile Screen Prototypes)
🎨

การออกแบบหน้าตาแอปพลิเคชันฝั่งผู้ใช้งาน (7 Mobile Screen Prototypes)

แสดงตัวอย่างหน้าจอการทำงานจริงบนโทรศัพท์มือถือ เรียงลำดับขั้นตอนการใช้งานจาก LINE ➔ เข้าสู่ระบบ ➔ แผงควบคุม ➔ ทำเนียบบุคลากร ➔ ปฏิทินรับใช้ ➔ การแจ้งเตือน ➔ โปรไฟล์ส่วนตัว

Screen 1: LINE Integration Gateway

1. LINE Rich Menu Gateway (ทางเข้าผ่านแอป LINE)

ผู้รับใช้สามารถเปิดใช้งานระบบได้ทันทีผ่านปุ่มเมนูลัดบน LINE Official Account โดยไม่ต้องดาวน์โหลดแอปพลิเคชันเพิ่ม

  • My Schedule: ปุ่มเข้าดูตารางการรับใช้ส่วนตัว
  • MTC Staff: ปุ่มดูรายชื่อทำเนียบบุคลากร
  • Car Reserve & Equipment: ปุ่มแจ้งจองยานพาหนะ และยืมอุปกรณ์
Screen 2: Authentication & Registration

2. Welcome Staff (หน้าลงทะเบียน & เข้าสู่ระบบ)

หน้าจอยืนยันตัวตนสำหรับผู้รับใช้ ปลอดภัยและใช้งานง่าย รองรับการกรอก Registration Code ประจำตัว

  • Registration Code Input: ช่องกรอกรหัสยืนยันตัวตน เช่น MC-1873-XXXX
  • Demo Mode Sandbox: มีรหัสทดสอบสำหรับให้ผู้บริหารและอนุกรรมการทดลองกดใช้งาน
  • Contact Admin Helper: ปุ่มกดขอความช่วยเหลือเมื่อลืมรหัสประจำตัว
Screen 3: Main Staff Hub

3. Staff Portal Dashboard (แผงควบคุมศูนย์รวมบริการ)

หน้าหลักสำหรับผู้รับใช้หลังเข้าสู่ระบบ รวมปุ่มลัดบริการหลัก การแจ้งเตือนข่าวสาร และข้อความต้อนรับส่วนบุคคล

  • Personalized Welcome: ข้อความทักทายชื่อผู้รับใช้ พร้อมตารางนัดหมายด่วน
  • Quick Action Grid: ปุ่มลัดเข้าสู่ Car Reserve, Equipment, Directory, และ Request Leave
  • Today Alert Notification: แจ้งเตือนข่าวสารและตารางรับใช้สำคัญประจำวัน
Screen 4: Directory & Contacts

4. Staff Directory (ทำเนียบบุคลากร & ช่องทางติดต่อ)

สมุดโทรศัพท์ดิจิทัลรวมรายชื่อศิษยาภิบาล มัคนายก และเจ้าหน้าที่สำนักงาน สะดวกต่อการประสานงานพันธกิจ

  • Search & Filter Tabs: ค้นหารายชื่อด้วยคำค้น หรือเลือกดูตามหมวด Pastors / Office / Other
  • Role Badges: แสดงตำแหน่งชัดเจน (Senior Pastor, Associate Pastor, Administrator, Sunday School)
  • One-Tap Call Button: ปุ่มกดโทรตรงหาผู้รับใช้ได้ทันทีจากหน้าจอ
Screen 5: Roster & Calendar Scheduler

5. MTC Schedule (ปฏิทินตารางรับใช้ & งานประจำวัน)

ปฏิทินแสดงตารางการปรนนิบัติรับใช้ส่วนบุคคลรายอาทิตย์และรายเดือน พร้อมรายละเอียดกำหนดการประจำวัน

  • Category Color Dots: จุดสีระบุประเภทภารกิจ (Worship, Meeting, Mission)
  • Today Agenda Timeline: ลำดับเวลาและสถานที่รับใช้ เช่น Morning Prayer (06:00 AM), Youth Meeting (02:00 PM)
  • Admin View Switcher: ปุ่มสลับไปยังหน้าจอผู้จัดตารางสำหรับศิษยาภิบาลและหัวหน้าฝ่าย
Screen 6: Notification & Alert Center

6. Notifications & Alerts (ศูนย์แจ้งเตือนพันธกิจ & ข่าวสาร)

ศูนย์รวมข้อความแจ้งเตือนด่วน ข่าวสารคริสตจักร และสถานะคำขออนุมัติ แยกตามระดับความสำคัญ

  • Urgent Prayer Request (แถบแดง): แจ้งคำอธิษฐานเร่งด่วนสำหรับสมาชิกและทีมงาน
  • Meeting & Leave Status (แถบส้ม/เขียว): แจ้งเตือนการประชุม และแจ้งผลการอนุมัติคำขอลา
  • New Roster Published (แถบฟ้า): แจ้งเตือนเมื่อตารางรับใช้ประจำเดือนใหม่ถูกเผยแพร่
Screen 7: User Profile & Governance

7. User Profile & Account Governance (โปรไฟล์ผู้ใช้งาน & สิทธิ์)

หน้าสรุปข้อมูลส่วนตัวของผู้รับใช้ สถิติจำนวนชั่วโมงการรับใช้ โควตาการลา และการตั้งค่าความเป็นส่วนตัว

  • Ministry Stats Dashboard: สรุปวันลาคงเหลือ (Leaves Days), ชั่วโมงรับใช้ (Hours), และภารกิจ (Tasks)
  • Contact & Security Info: เบอร์โทรศัพท์ อีเมลสถาบัน และสถานะการออนไลน์
  • Governance & Support Settings: เมนูตั้งค่าการแจ้งเตือน ความปลอดภัย (Privacy & Security) และศูนย์ช่วยเหลือ
💻 4. ระบบหลังบ้านสำหรับการบริหารจัดการคริสตจักร (Backoffice CRM & Admin Portal)
🖥️

ระบบ CRM และแผงควบคุมผู้ดูแลระบบ (Executive Backoffice Dashboard)

ศูนย์กลางบริหารจัดการสำหรับเจ้าหน้าที่คริสตจักร ศิษยาภิบาล และคณะอนุกรรมการ เชื่อมโยงข้อมูลกับแอปหน้าบ้าน real-time

🛠️ 6 โมดูลบริหารหลักในระบบหลังบ้าน (Core CRM Modules Showcase):

1. Executive Overview Analytics

สรุปจำนวนบุคลากรประจำการ (Total Staff), อัตราการเข้ามาร่วมรับใช้, และกราฟสถิติสรุปภาพรวมพันธกิจ

2. Serving Roster Master Calendar

หน้าจอจัดตารางรับใช้ มน. x ศบ. แบบรวมศูนย์ ช่วยเช็กตารางชนและคำนวณโควตาอัตโนมัติก่อนส่งเตือนเข้า LINE

3. Equipment Inventory & QR Code

คลังอุปกรณ์พร้อมสถานะ real-time (พร้อมใช้/ถูกยืม/ซ่อม) ตรวจดูลายเซ็นดิจิทัลผู้ยืม และพิมพ์ QR Code

4. Repair SLA Tickets & Support Monitor

ติดตามใบแจ้งซ่อมตามระดับความสำคัญ (Low/Medium/High/Critical) และนับเวลาถอยหลัง SLA ช่างซ่อม

5. Member & Staff Data Registry CRM

ตู้เซฟฐานข้อมูลทะเบียนบุคลากร จัดการสิทธิ์เข้าถึง (RBAC) และรองรับการอัปโหลดไฟล์ Excel นำเข้าข้อมูลชุดใหญ่

6. Audit Log & System Governance

ระบบบันทึกประวัติทำรายการ (Who/What/When/Device) บริหารจัดการสิทธิ์ใช้งาน และสำรองข้อมูลนิรภัย

🌐 High-Level Logical Architecture Overview

สถาปัตยกรรมระบบ MTC Staff Management System (4-Tier Cloud Architecture)

โครงสร้างการเชื่อมต่อตั้งแต่ช่องทางผู้ใช้งาน (LINE & Web) ผ่าน Edge Gateway เข้าสู่ Core API Serverless และ Supabase PostgreSQL

📱 Tier 1: User Presentation & Client Channels (ช่องทางผู้ใช้งาน)
💬 LINE App (LIFF Gateway)
เข้าผ่าน LINE Official Account ไม่ต้องโหลดแอป รองรับ SSO & Quick Rich Menu
💻 Web Browser (Mobile & Desktop)
หน้าเว็บ PWA/Responsive UI สำหรับบุคลากร และศิษยาภิบาลเข้าดูข้อมูล
🖥️ Backoffice CRM Admin Portal
แผงควบคุมระบบหลังบ้านสำหรับเจ้าหน้าที่คริสตจักร บริหารทะเบียน & อุปกรณ์
⬇️ (HTTPS / REST API / LIFF SDK / LINE Webhook Events) ⬇️
⚡ Tier 2: Cloud Gateway & Messaging Integration (ระบบเกตเวย์ & การสื่อสาร)
🛡️ Vercel Edge CDN & Firewall
SSL/TLS 256-bit Encryption, Auto-scaling Serverless Endpoint, Rate Limiting
🤖 LINE Messaging API Webhooks
รับ-ส่งข้อความอัตโนมัติ Verified Signature (`x-line-signature`) ส่ง Push Notifications
⬇️ (Serverless Function Route Execution) ⬇️
⚙️ Tier 3: Next.js 15 Application Core & Business Engines (ประมวลผล Business Logic)
📅 Roster Scheduler Engine
/api/roster - จัดตาราง มน. x ศบ. ตามกฎ 4 ข้อ + Auto-Substitute Finder เมื่อมีการสลับวัน
📦 QR Equipment & Handover
/api/bookings/equipment/* - สแกน QR Code + บันทึกลายเซ็นดิจิทัล Base64 Signature Canvas
🔧 Repair SLA Ticket Engine
/api/tickets & /api/cron/sla-check - คำนวณเวลา SLA (4h-72h) & Cron Monitoring
🔐 Auth & Member Registry
/api/staff & /api/profile - ตรวจสอบสิทธิ์ RBAC & ข้อมูลทะเบียนบุคลากรปลอดภัย
⬇️ (Prisma ORM / Connection Pooling) ⬇️
🗄️ Tier 4: Managed Cloud Database & Storage (ฐานข้อมูลนิรภัย)
🐘 Supabase PostgreSQL DB
เก็บข้อมูล Staff, Roster, Equipment, Signatures, SLA Tickets (Prisma Schema)
🔒 Storage & Audit History
จัดเก็บไฟล์รูปภาพอุปกรณ์ หลักฐานการแจ้งซ่อม และบันทึก Audit Logs
💡 จุดเด่นด้านสถาปัตยกรรม (Key Arch Highlights)
  • Fullstack Integration: ใช้ Next.js 15 รวมหน้าบ้านและหลังบ้านไว้ในโปรเจกต์เดียว ดูแลง่าย
  • Zero Infrastructure Overhead: ไม่ต้องซื้อ Server มาตั้งที่คริสตจักร รันบน Vercel + Supabase 100%
  • LINE Native Experience: ผู้รับใช้ใช้งานผ่าน LINE ที่คุ้นเคย โดยไม่ต้องลงแอปพลิเคชันใหม่
🛡️ ความปลอดภัย & PDPA Compliance
  • Data Encryption: เข้ารหัสข้อมูลการสื่อสารด้วย HTTPS TLS 1.3 สองทางตลอดเวลา
  • Role-Based Access Control: จำกัดสิทธิ์ดูข้อมูลตามบทบาท (ศิษยาภิบาล / มัคนายก / ช่าง)
  • Non-Repudiation Audit: มีระบบบันทึกลายเซ็นดิจิทัลพร้อม Timestamp ป้องกันการปฏิเสธความรับผิดชอบ

❓ 11. คู่มือตอบคำถามคณะอนุกรรมการ (Executive Q&A Cheat Sheet)
❓ 1. ทำไมบางหน้าดูสวยงามแล้ว แต่รายงานว่ากำลังผูก Logic หลังบ้าน?
💡 คำตอบ: เป็นแนวทาง Agile Design ครับ เราสร้างหน้าตา UI ออกมาให้ทีมงานเห็นภาพตรงกันก่อน จากนั้นจึงทยอยผูกสายไฟเข้ากับฐานข้อมูลจริงทีละส่วน ซึ่งโมดูลอุปกรณ์และแจ้งซ่อมผูกสำเร็จ 100% แล้วครับ
❓ 2. คนที่ไม่เก่งคอมพิวเตอร์ หรือผู้สูงอายุจะใช้งานได้จริงไหม?
💡 คำตอบ: ใช้งานได้แน่นอนครับ ผู้รับใช้กดเข้าผ่าน LINE บนมือถือเครื่องเดิม ปุ่มกดขนาดใหญ่ ตัวหนังสืออ่านง่าย เพียงยกมือถือสแกน QR Code ก็ยืมอุปกรณ์ได้แล้วครับ
❓ 3. ข้อมูลส่วนตัวและทะเบียนคริสตจักรจะหลุดออกไปข้างนอกหรือไม่?
💡 คำตอบ: ปลอดภัยสูงสุดตามมาตรฐาน PDPA ครับ เข้ารหัสข้อมูล HTTPS ระดับเดียวกับธนาคารดิจิทัล มีการล็อกสิทธิ์เข้าถึง (RBAC) คนภายนอกจะไม่สามารถมองเห็นข้อมูลได้เลยครับ
❓ 4. คริสตจักรต้องเสียค่าดูแลรักษาระบบ (Maintenance) แพงไหมในระยะยาว?
💡 คำตอบ: ค่าใช้จ่ายต่ำมากครับ เพราะเลือกใช้บริการ Cloud สากลที่คริสตจักรไม่ต้องซื้อเซิร์ฟเวอร์มาตั้งเอง และโครงสร้างโปรเจกต์เขียนด้วยมาตรฐานสากล ทีม Dev รุ่นถัดไปมาดูแลต่อได้ง่ายครับ
